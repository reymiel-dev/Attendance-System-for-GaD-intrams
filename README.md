## Student Attendance Management System

A web-based attendance management system developed using PHP and MySQL. It was used during the school's Intramurals booth game to manage participant attendance through student ID lookup and automatic attendance recording.

## Features

- Student ID lookup
- Automatic attendance recording
- Student information retrieval
- Daily attendance count
- Attendance records table
- CSV export of attendance records

## Built With

- PHP - Backend processing
- MySQL - Database management
- HTML - Page structure
- CSS - Interface styling
- XAMPP - Local development environment

## Requirements

- XAMPP
- PHP
- MySQL
- Web browser

## Installation

1. Clone or download this repository.

2. Place the project folder inside XAMPP's "htdocs" directory.

3. Start Apache and MySQL using the XAMPP Control Panel.

4. Open phpMyAdmin.

5. Create a database named "attendance_db".

6. Import the project's SQL database file, if provided.

7. Configure the database connection in "config/database.php".

8. Open the project in your browser:
   
   "http://localhost/attendance-system/"

## Project Purpose

Developed as an academic project to apply PHP programming, database management, and web development concepts. The system was implemented during the school's Intramurals booth game to help manage participant attendance and keep track of attendance records.
